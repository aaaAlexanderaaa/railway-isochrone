铁路可达圈

回答一个问题：在当前地点、时间和预算下，铁路实际能把我带到哪些地方？

  1. 填出发地，和订票一样。
  2. 叠加等时圈、取交集——第②步再建 1–3 个圈：别的出发地（不同城市的朋友各建一个），或「必须抵达某地」的圈（如明天 12:00 前到白云机场、或赶回出发地）。查询后自动算出所有圈的共同城市——大家都能到的碰头地。一个都没有 = 没有重叠，不是查失败。
  3. 设定单程时间预算（如 3–4 小时）— 地图与列表展示该时间带内的现实可达目的地。
  4. 理解每个目的地 — 不只看"最快"：典型耗时、方案数、直达班次。点开一行看具体车次。
  5. 点击地图圆点或列表行查看当日方案时间轴与具体车次行程。
  6. 底图与天气 — 可切到卫星影像看山湖地貌；雨云/温度/风是未来十余天的全国预报图层（一眼看哪片在下雨），预警叠中央气象台正在发布的信号。预报求「大部分可靠」，不是点对点气象保证。
术语说明
典型耗时：主档方案耗时的中位数——比"最快"更接近你实际会坐的那趟。
主档方案：耗时不超过 min(预算上限, 最快+2小时) 的方案；表格里的"方案数 / 直达 / 典型 / P90"均按此口径，更慢或超预算的车不计入（在时间轴上淡色显示）。
P90 耗时：主档方案耗时的 90 分位——错过最优车次后大约会变成多久。
≈ 标记：典型耗时略低于预算下限（30 分钟弹性内）；把预算当"上限"理解时它同样符合。
后续约束列：叠加了「必须抵达」圈时，显示从该城市出发、仍能在截止前赶到圈目的地的最晚时刻（同城各站取最大）；叠加多个圈时逐圈显示各自情况，⊕ 白点标记 = 各圈交集城市。

数据：中国铁路时刻表（社区 GTFS，周更快照；班次与站数见顶栏）。方案为时刻表演算结果，未含购票限售、临时调度、票价余票等因素。部分车次号带 A/B/C 等后缀（如 C4187B），是同号复开的真实不同班次；斜杠双号（如 G463/G466）是跨线运行中变更车次的同一列车——均非数据重复。
