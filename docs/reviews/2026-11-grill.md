   生成器没有本项目消费者。

## 独立架构审查与处置

首轮审查使用新上下文，未提供本文作者理由。报告9类问题：

1. 更新未连部署 → 新增显式可复用 deploy-pages 工作流。
2. 更新非事务 → 隔离下载/ETL/验证，通过后替换，故障回滚测试。
3. 正向稀疏路网、直达、后续换乘、昨天始发漏解 → 按每日实例计算最早上车，
   每个乘车层保留非支配方案；固定小路网回归。
4. 保存地点下标漂移 → 稳定站名解析和旧格式迁移。
5. 预算更改不重算 → 主查询与圈共用 JourneyStats，预算变化重新派生结果。
6. 日期午夜零值和不限预算语义 → 保留零值，不限统计按无穷上限。
7. 归档按发布日期误删 → 本地保存时间与 manifest.previous。
8. 过期不提示 → 超14天提示，检测新版本提供重载。
9. README与实际入口不同 → 改写为可执行命令并修复浏览器平台路径。

原审查者第二轮确认上述多数问题关闭，并独立用200个固定小路网与路径枚举对照
反向引擎，全部一致。后续发现：

- 本站到发逆序被漏检 → 新校验；113处终点出发规范化，79趟中途逆序列车整趟剔除，
  全部计数记录在快照 meta.quality，测试覆盖。
- 不限统计仍误截 → 统计统一模块修复（不是只修过滤）。
- 恢复丢失地点提示被覆盖 → 启动末尾保留提醒。
- fare请求误走Worker且未路由 → 恢复独立HTTP与Functions路由。
- 旧更新任务可能覆盖新部署 → 最终部署前fetch并核对当前main，旧版本跳过。
- 摘要修复引入未定义cityMaxStop → 表格恢复使用所选stopI；浏览器新增返程场景。
- 地图交集tooltip取错对象层级导致NaN → 统一读st.typ / info.latest。
