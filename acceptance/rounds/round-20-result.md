## 本轮交付的相关验证

- 数据协议 v2：全国格点 3h 步长（128 步 × 640 点，Open-Meteo `temporal_resolution=hourly_3`，实测降水按窗口累计、日总量守恒）；单点多模型端点（best_match/ECMWF/GFS/ICON，ICON 约 7.9 天后缺测为 null）。
- 缓存：本地 grid 6h / point 3h（FIFO+singleflight）/ 预警 5min；响应头 grid·point `max-age=10800`、预警 `max-age=300`；CF 端 grid·point 走 Cache API，预警补 5min 边缘缓存。三处抓取代码收敛为 `public/weather_core.js` 单一实现（CF Functions 经 esbuild 校证打包通过）。
- UI：底部 3h 时间轴（16 天刻度、播放、与出发日联动）、右下天气面板（图例/出处 + 📍探针多模型气象图）、图例并入图层面板且默认收缩、配色固定绿快红慢、大表降级为按需展开、候选清单（★ 收藏 + 到达时天气 + localStorage 持久化）、天气图层选择会话恢复（修"只存不读"缺陷）。
- 429 防护：Open-Meteo 限流退避从 0.7s 级加长到 5s/10s/15s（分钟级限流窗）。
- 回归：`node test_engine.js` 通过；browse.js 冒烟（默认值/示例/时间轴/探针/收藏/表格降级/恢复）无控制台错误。
